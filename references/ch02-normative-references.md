# Clause 2 — Normative references

LRM p. 26.

이 표준을 적용하려면 아래 문서가 필수(indispensable)다. 날짜 표기가 있는 참조는 해당 판만, 없는 참조는 최신 판(개정 포함)이 적용된다.

- **ISO/IEC 14882:2017**, *Programming languages — C++*.

즉 SystemC의 유일한 normative 외부 참조는 C++17 표준이다. → 언어 기능·용어(예: undefined behavior, well-formed, lvalue)의 정의는 C++17을 따른다.
